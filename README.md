## 📖 About

**WafyURL** is a premium full-stack link management platform built to make URL shortening and link management simple, fast, and powerful.

It combines URL shortening with analytics, QR code generation, password protection, bulk shortening, and link preview features in one modern platform.

## ✨ Features

- ⚡ Lightning Fast URL Shortening
- 📊 Analytics Dashboard
- 📱 QR Code Generation
- 🔐 Password Protected Links
- 📦 Bulk URL Shortening
- 🔍 Link Preview
- 🎨 Modern User Interface
- 📱 Responsive Design

## 🛠️ Tech Stack

- Python
- Flask
- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/afeemuhammodwafy1/wafyurl.git
cd wafyurl
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run locally

```bash
python app.py
```

Then open:

```text
http://localhost:5000
```
